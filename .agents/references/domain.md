# Domínio

Vocabulário canônico: `CONTEXT.md`.

| Superfície | Papel |
| --- | --- |
| Mapa | Home. Tiles + overlay. Seletor nativo de Dimensão. Sem alta de pin. |
| Marcadores | Lista (todas as Dimensões; ordem Overworld → Nether → End, depois nome). Alta/edição/exclusão. Ver no mapa. |
| Configuração | Importar / Atualizar mapa / Substituir fonte. Status mínimo. |

Fonte de Mapa: uma por vez. Atualizar = merge de marcadores (ADR 0004). Substituir = wipe só se o passo de marcadores concluir.

Fora do MVP: iOS, multi-world, Rotas/Eixos da ferrovia (`docs/specs/pos-mvp-ferrovia.md`), parser Bedrock, sync cloud.
